## Requirements

### Functional Requirements

- [x] Mock-first UI development with easy toggle between mock/real data modes — Validated v1.0
- [x] Chat interface with RAG Search and LLM Chat modes — Validated v1.0
- [x] Client-side streaming responses for ChatGPT-like UX — Validated v1.0
- [x] Message history persistence with user-scoped Directus storage — Validated v1.0
- [x] Knowledge base document browsing with folder hierarchy and CRUD — Validated v1.0
- [x] Custom Directus login with purple theme and Russian localization — Validated v1.0
- [x] Protected routes with authentication and role-based access — Validated v1.0
- [x] Sidebar navigation with company branding and user initials — Validated v1.0
- [x] Purple theme (#8466e4) with modern visual polish — Validated v1.0
- [x] Container monitoring dashboard via Portainer API — Validated v1.0
- [x] Three-tier RBAC (administrator/moderator/user) with UI gating — Validated v1.0
- [x] File management (upload, download, edit, move, delete) — Validated v1.0

### Non-Functional Requirements

- [x] Localhost Docker deployment — Validated v1.0
- [x] React + TypeScript + Vite + Tailwind CSS + Shadcn/UI stack — Validated v1.0
- [x] Prettier + ESLint + VSCode format-on-save — Validated v1.0
- [x] Nginx routing for all API traffic — Validated v1.0
- [x] Russian localization for all user-facing text — Validated v1.0

### Out of Scope (v1.0)

- Mobile optimization — desktop-first, PWA not yet explored
- Advanced AI features (multi-model, fine-tuning) — current RAG + LLM covers needs
- User management UI — admin manages users through Directus directly
- Offline mode — real-time connectivity is core value
