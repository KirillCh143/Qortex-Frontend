## Requirements

### Validated

- [x] Mock-first UI development with easy toggle between mock/real data modes — v1.0
- [x] Chat interface with RAG Search and LLM Chat modes — v1.0
- [x] Client-side streaming responses for ChatGPT-like UX — v1.0
- [x] Message history persistence with user-scoped Directus storage — v1.0
- [x] Knowledge base document browsing with folder hierarchy and CRUD — v1.0
- [x] Custom Directus login with purple theme and Russian localization — v1.0
- [x] Protected routes with authentication and role-based access — v1.0
- [x] Sidebar navigation with company branding and user initials — v1.0
- [x] Purple theme (#8466e4) with modern visual polish — v1.0
- [x] Container monitoring dashboard via Portainer API — v1.0
- [x] Three-tier RBAC (administrator/moderator/user) with UI gating — v1.0
- [x] File management (upload, download, edit, move, delete) — v1.0

### Out of Scope

- Mobile optimization — desktop-first, PWA not yet explored
- Advanced AI features (multi-model, fine-tuning) — current RAG + LLM covers needs
- User management UI — admin manages users through Directus directly
- Offline mode — real-time connectivity is core value
