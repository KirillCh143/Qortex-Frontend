## Decisions Made

- **Folder filtering approach**: Used special 'root' string value to filter for null folders, regular folder IDs for specific folders. This provides clean API for callers.
- **Mock folder structure**: Created realistic 3-level hierarchy mirroring common organization (HR/Policies, HR/Benefits, Engineering/Documentation, Engineering/Guidelines). Maps existing mockDocuments to appropriate folders.
- **Click behavior**: Single click on folder both toggles expand/collapse AND selects it for filtering. This provides intuitive UX where expanding a folder also shows its contents.
- **Expand state management**: Stored in local component state using Set for O(1) lookup. Not persisted across unmounts - folders start collapsed on each render.
