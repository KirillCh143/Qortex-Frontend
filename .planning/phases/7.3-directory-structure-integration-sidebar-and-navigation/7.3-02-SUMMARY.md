## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed duplicate download trigger**

- **Found during:** Checkpoint verification (user testing after plan execution)
- **Issue:** Download button triggered TWO downloads:
  1. JSON file containing file metadata
  2. Actual file with correct name but corrupted content (same size as JSON, won't open)
- **Root cause:** `downloadFile()` method in `files.service.ts` was calling `client.request(readFile(id))` to fetch metadata, then separately fetching blob from `/assets/{id}`. The metadata request triggered an unwanted download.
- **Fix:** Removed unnecessary `readFile()` call - fetch blob directly from assets endpoint only
- **Files modified:** `src/services/directus/files.service.ts`
- **Verification:** Download now triggers single file download with correct content and filename
- **Committed in:** `f43f2ec` + `08039ac` (fix + cleanup)
