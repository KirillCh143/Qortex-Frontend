**Discovery findings:**
- Directus has `directus_folders` collection with `id`, `name`, and `parent` fields
- Directus SDK provides `readFolders()` function for querying folder hierarchy
- `directus_files` has a `folder` field (UUID) that can be filtered using `filter: { folder: { _eq: 'folder-id' } }`
- Null folder means root level files

**Tech stack available:**
- React Query for data fetching
- Directus SDK with readFolders and readFiles
- Existing mock service pattern for real/mock toggle
