<task type="checkpoint:human-action" gate="blocking">
  <action>Configure Directus server for longer session duration</action>
  <instructions>
    Directus sessions are expiring too quickly. Please extend the session duration in your Directus server configuration:

    **If using Directus Docker/standalone:**
    1. Locate your Directus `.env` file (server-side, not frontend)
    2. Add or update these environment variables:
       ```
       ACCESS_TOKEN_TTL="7d"
       REFRESH_TOKEN_TTL="30d"
       ```
    3. Restart Directus server for changes to take effect

    **If using Directus Cloud:**
    1. Login to Directus Cloud dashboard
    2. Navigate to your project settings
    3. Under "Security" or "Authentication" settings
    4. Set Access Token TTL to 7 days
    5. Set Refresh Token TTL to 30 days
    6. Save and restart project

    **Default behavior:** Directus uses 15-minute access tokens and 7-day refresh tokens by default. We're extending access tokens to 7 days so users stay logged in until they manually logout.

    **Security note:** Longer tokens mean users stay authenticated longer. This is appropriate for internal employee tools but adjust based on your security requirements.
  </instructions>
  <verification>After configuration, I'll test by logging in and verifying the session persists across browser refreshes without re-login prompts</verification>

Add environment variable to control ReactQueryDevtools visibility following Phase 7 patterns:

```

```

**`src/providers/QueryProvider.tsx`** - Conditionally render DevTools:
1. Import at top: `const showDevTools = import.meta.env.VITE_SHOW_DEVTOOLS === 'true'`
2. Update ReactQueryDevtools conditional:
   ```typescript
   {showDevTools && (
     <ReactQueryDevtools initialIsOpen={false} />
   )}
   ```
3. Add comment explaining: `// DevTools controlled by VITE_SHOW_DEVTOOLS env var (default: true in dev, false in prod)`

This follows the exact same pattern as VITE_USE_MOCK_DATA. When building for production, set VITE_SHOW_DEVTOOLS=false in build environment to exclude DevTools from bundle.

**Why this matters:** ReactQueryDevtools adds ~50KB to bundle. Environment toggle allows developers to use it locally while keeping production builds clean.
