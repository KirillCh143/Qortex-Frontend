## Decisions Made

- **Chat storage in Directus:** Messages stored with user foreign key for privacy. Each user can only read/create their own messages via permissions (user = $CURRENT_USER).
- **React Query staleTime: 0:** Always fetch fresh chat history on mount to ensure latest messages from Directus.
- **Mock service pattern:** Map keyed by userId simulates user-specific storage in mock mode for consistent behavior.
- **Type suppression:** Used `@ts-ignore` for Directus SDK custom collection calls since SDK v20 requires schema definitions that don't easily extend to runtime collections.
