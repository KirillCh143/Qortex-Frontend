  1. Import `useAuth` from AuthContext
  2. Define the `UserRole` type: `'administrator' | 'moderator' | 'user'`
  3. Return an object with these computed boolean properties:
     - `role`: the raw role string (or `'user'` as fallback if somehow null)
     - `canAccessSettings`: true only for `administrator` (Settings/Portainer page)
     - `canManageFiles`: true for `administrator` and `moderator` (create folder, upload, edit, delete in Knowledge Base)
     - `isAdministrator`: true only for `administrator`
     - `isModerator`: true for `administrator` or `moderator`
  4. Keep it simple - no complex permission matrices. The hierarchy is:
     - administrator: everything
     - moderator: everything except Settings page
     - user: everything except Settings page and file management (CRUD)
  5. Export the `UserRole` type for reuse.
  6. Do NOT over-engineer. No permission config objects, no role arrays, no middleware patterns. Simple boolean checks.
  </action>
