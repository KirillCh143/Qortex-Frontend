## Decisions Made

1. **Purple color scheme (#8466e4)** - Replaced old blue theme for login page to match reference design
2. **Gradient from-primary to-[#a18cf0]** - Logo circle background gradient
3. **Russian text throughout** - Matching reference design exactly ("Nexus AI", "Вход в систему", "Войти", copyright footer)
4. **Hardcoded hex colors for button** - Used bg-[#8466e4] instead of bg-primary to bypass Tailwind variable caching issues
5. **rounded-3xl for all form elements** - Inputs and button use same radius as card container for visual consistency
6. **h-14 fixed height** - All form elements (email, password, button) have consistent 56px height
7. **navigate with replace: true** - Prevents back button issues, consistent with ProtectedRoute pattern
8. **Redirect trigger condition** - Only when !loading && isAuthenticated to avoid flash during auth check
9. **Native button element** - Replaced Button component to have full control over styling
