<task type="auto">
  <name>Task 2: Implement view and download handlers</name>
  <files>src/pages/KnowledgeBase.tsx</files>
  <action>
Replace placeholder alert() functions with working implementations:

**View handler (handleView):**
1. Call generateMockFileContent(selectedDoc) to get Blob
2. Create blob URL with URL.createObjectURL(blob)
3. Open in new tab with window.open(url, '_blank')
4. Clean up blob URL after short delay (setTimeout 100ms, URL.revokeObjectURL)

**Download handler (handleDownload):**
1. Call generateMockFileContent(selectedDoc) to get Blob
2. Create blob URL with URL.createObjectURL(blob)
3. Create anchor element: `const a = document.createElement('a')`
4. Set a.href = url, a.download = selectedDoc.filename
5. Append to body, click programmatically, remove from DOM
6. Clean up blob URL immediately after

Import generateMockFileContent from '@/lib/mockDocuments'.

Both handlers should work when user clicks View or Download buttons in detail panel.
  </action>
  <verify>npm run build succeeds, clicking View opens mock content in new tab, clicking Download triggers browser download with correct filename</verify>
  <done>View button opens mock file content in new tab, Download button triggers browser download with document filename, both use generated Blob content, no errors in console</done>
</task>
