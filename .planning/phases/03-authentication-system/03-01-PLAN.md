    Create src/contexts/AuthContext.tsx implementing the pattern from DISCOVERY.md Section 6.1.

    AuthContext must provide:
    - user: User | null (with id, email, first_name, last_name fields)
    - loading: boolean (critical for preventing race conditions on page load)
    - login: (email: string, password: string) => Promise&lt;void&gt;
    - logout: () => Promise&lt;void&gt;
    - isAuthenticated: boolean (computed from !!user)

    Implementation requirements:
    - useEffect on mount to check existing auth (checkAuth function)
    - checkAuth validates localStorage token by calling readMe() from @directus/sdk
    - If readMe() fails, clear localStorage and set user to null
    - login() calls client.login(), stores result in localStorage, then calls checkAuth()
    - logout() calls client.request(logout()) with refresh_token from localStorage, clears storage, sets user null
    - Export useAuth() hook that throws error if used outside AuthProvider

    Use client.login(), NOT manual fetch - SDK handles token storage automatically. Use consistent 'json' mode for all operations (DISCOVERY.md Section 10.4 pitfall).

    Wrap the App component in main.tsx with AuthProvider (inside BrowserRouter, outside App).
  </action>
